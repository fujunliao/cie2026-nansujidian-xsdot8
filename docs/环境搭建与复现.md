# 环境搭建与复现

## 已验证的机器

Windows 16 GB 主机，WSL2 Ubuntu 22.04.5；WSL 内存 10 GB、24 GB swap。JDK 21.0.12 GraalVM、Mill 0.12.3、Verilator 5.052、riscv64-linux-gnu GCC 11.4.0；Yosys 0.9、Icarus Verilog、GTKWave 的 fst2vcd。版本和路径以 `results/system/environment.log` 为准。

WSL 的 `.wslconfig` 示例（需要用户保存并重启 WSL 后生效）：

```ini
[wsl2]
memory=10GB
swap=24GB
swapFile=D:\\WSL-Swap\\xiangshan-swap.vhdx
```

Linux 文件系统实际位于 C 盘。swap 在 D 盘不意味着源码和 build 在 D 盘，编译前同时检查两盘剩余空间。已有编译正在运行时不要关闭 WSL。

## 工具准备

按香山官方 xs-env 的 README 安装固定版本的 Java、Mill、LLVM、Verilator 和交叉编译器。Java 必须匹配上游构建要求；本次 JAVA_HOME 为 `/opt/graalvm-jdk-21`，LLVM 路径为 `/usr/local/llvm/bin`。不建议仅用 Ubuntu 默认旧版 Verilator 替换本次版本。

基础依赖示例：

```bash
sudo apt update
sudo apt install git build-essential python3 gawk bison flex help2man \
  libreadline-dev libsdl2-dev libelf-dev device-tree-compiler zlib1g-dev \
  gcc-riscv64-linux-gnu g++-riscv64-linux-gnu binutils-riscv64-linux-gnu \
  yosys iverilog gtkwave
```

此命令是基础包列表，不代替 xs-env 的完整工具版本安装。官方入口：https://github.com/OpenXiangShan/xs-env 。当前电脑已经有可用工具链，无需重装。

## 固定源码和构建

在解压包根目录先执行 `python3 tools/verify_package.py`。`upstream-lock.json` 固定 XiangShan、NEMU、nexus-am 和所有香山 submodule 的实际提交，原始 nexus-am 跟踪源码与测试用副本一致。`prepare_sources.sh` 拉取版本后以文件校验的方式应用补丁；目标目录已存在会停止。

```bash
bash tools/prepare_sources.sh "$HOME/projects/xsdot8-reproduce"
export JAVA_HOME=/opt/graalvm-jdk-21
export PATH="$JAVA_HOME/bin:/usr/local/llvm/bin:$PATH"
bash tools/build_and_test.sh "$HOME/projects/xsdot8-reproduce"
```

核心构建命令：

```bash
make emu CONFIG=KunminghuV2MinimalConfig JVM_XMX=12G EMU_THREADS=1 EMU_TRACE=fst -j4
```

10 GB 物理上限和 12 GB JVM 最大堆需要 swap；最大堆不是立即分配量。本次在该配置上完成了干净 Chisel 至 Verilator 编译，但换机器后的运行时间和内存情况需重新观察。避免同时运行多份 RTL 生成。

本配置补丁将 Minimal CHI LLC 的 `fullAddressBits` 设置为 SoC `PAddrBits`，修复当前上游最小配置地址切片越界。该修改与 vdot 无关，补丁中单独可审阅。公开赛题指定昆明湖 V2，未在查阅的材料中指定 Config 类名；请据最新赛事通知决定是否要求完整配置重测。

## 验证与波形

```bash
bash tools/verify.sh
python3 tools/extract_nemu_helper.py
gcc -O2 -Wall -Wextra -Werror tests/nemu_helper_harness.c -o /tmp/xsdot8-helper
/tmp/xsdot8-helper
iverilog -g2012 -s datapath_tb -o /tmp/xsdot8-datapath rtl/VDot.sv tests/datapath_tb.sv
# 会在当前目录生成 datapath.vcd
vvp /tmp/xsdot8-datapath
```

模块测试不替代整机差分。整机命令必须使用修改后的 emu、NEMU 参考库与 AM 镜像；`run_existing.sh all` 检查进程退出和 GOOD TRAP。NEMU 的测试 defconfig 包含匹配香山的三条启动 ROM 指令；软件显式初始化 VS、NMIE 和 MDT。

`results/waves/selected.vcd` 可直接使用 GTKWave；`selected-signals.json` 映射精简信号名至原始层次路径。`python3 tools/extract-wave.py` 从原始向量加法 FST 重新提取；`python3 tools/extract-wave.py throughput.fst` 提取吞吐实验；然后使用 `analyze-wave.py` 及 `analyze-wave.py throughput`。解析会产生较大的中间 JSON，需要预留空间。横轴是 guest cycle，不是物理时间。

首次安装的桌面历史录像不在本包中。三份 MP4 来自实际 PTY 执行时序和实测图表，`.cast` 保留源记录，章节 JSON 写明回放倍率。
